<Briefing title="A confidence interval for the slope, and the claims it can settle" topics={["9.2", "9.3"]}>
<Briefing.Intuition>
A fitted slope $b$ is a single estimate of the population slope $\beta$, and by itself it has no error bar on it. The interval supplies one, and it is built exactly like every other $t$ interval in the course: **statistic ± critical value × standard error.**

$$b \pm t^\star \cdot SE(b), \qquad df = n - 2$$

Both ingredients come off computer output. The **Coef** column gives $b$, the **SE Coef** column beside it gives $SE(b)$, and $t^\star$ comes from a $t$ table or a calculator at the chosen level on $n - 2$ degrees of freedom. The $n - 2$ is the only thing about a slope interval that is not already familiar, and it is where marks are lost: two parameters were estimated to place the line, so two degrees of freedom are gone.

**Interpreting it.** The interval is a set of plausible values for the **true slope** of the population regression line, and a slope is a rate, so the interpretation must carry its units:

> We are 95% confident that the true slope of the population regression line of *[response]* on *[explanatory]* for *[population]* is between *[low]* and *[high]* *[units of y per unit of x]*.

Every part of that sentence is load-bearing. "True" or "population", because the interval estimates a parameter and not the $b$ already in hand. Both endpoints. The units, which for a slope are always *something per something*. And the population, which is whatever set of units the sample was drawn from and no wider.

**Justifying a claim.** An interval answers any question of the form *is $\beta$ equal to some particular value?* by whether that value is inside it.

- If the value is **outside** the interval, the data give convincing evidence, at that level, that $\beta$ is not that value, and the side it falls on says which way.
- If the value is **inside**, the data are consistent with it. That is not evidence that $\beta$ equals it; the interval is consistent with every other value it contains too.

Most textbook questions ask about zero, because zero means "no linear relationship". That is a special case rather than the rule. The value the interval is checked against is whatever value the problem's science, contract or specification requires: a rate of light delay per AU, a kilonewton per tonne-milligee, a tonne of fuel per tonne of required fuel. **When physics or a specification fixes what the slope has to be, the interval is tested against that number and zero never enters it.**

**Width.** The half-width is $t^\star \cdot SE(b) = t^\star s / \sqrt{S_{xx}}$, so an interval narrows when:

- $n$ rises, both through $S_{xx}$ and through a smaller $t^\star$ on more degrees of freedom;
- $s$ falls, meaning the points sit closer to their own line;
- the $x$ values are spread further apart, which raises $S_{xx}$ without needing another observation;
- the confidence level is lowered, which is buying precision with reliability rather than with data.
</Briefing.Intuition>

</Briefing.Worked>
<Briefing.Caution>
*$df = n - 2$.* A slope procedure spends two degrees of freedom, one on the intercept and one on the slope. Using $n - 1$ gives a $t^\star$ that is slightly too small and an interval that is slightly too narrow, which is the direction that costs you: the interval will exclude values it should have kept.

*The interval is about the parameter, not about the data.* Of the relay net above, "the station slopes in the data run from {fmt(relayInterval.ci[0], 3)} to {fmt(relayInterval.ci[1], 3)}" is not what the interval says, and it is not even a sentence about a real quantity, because those twelve stations have exactly one fitted slope. The interval is a set of plausible values for the one true slope of the process.

*Confidence is a property of the method.* Ninety-five percent of intervals built this way, from samples of this kind, capture the true slope. This particular interval either contains $\beta$ or it does not, and nothing in the arithmetic says which.

*A value inside the interval has not been established.* An interval that contains 1.00 is consistent with a slope of exactly one, and equally consistent with every other value between its endpoints. Reporting it as "the slope is one" claims a precision the procedure did not buy.

*Conditions come first and are checked on the residuals.* An interval computed on data that fan, or curve, is an interval with the wrong width, and neither the output nor the calculator will say so.
</Briefing.Caution>
</Briefing>
